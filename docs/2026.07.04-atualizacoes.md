## 2026-07-04 — Componente MenuBar e Barra de Busca

### Contexto

Sessão de desenvolvimento focada em adicionar uma barra de navegação global (`MenuBar`) e um sistema de busca client-side acessível via atalho de teclado `Ctrl+K` / `Cmd+K`. Durante a implementação, foram identificados e corrigidos dois erros de runtime: incompatibilidade de versões do React e uso indevido de API Route em modo de exportação estática.

#### 2. Componente `SearchButton` — Busca via `Ctrl+K` / `Cmd+K`

**Arquivos criados:**

| Arquivo | Propósito |
| --- | --- |
| `src/app/components/SearchButton.tsx` | Client Component com modal de busca e atalhos de teclado |
| `src/app/components/SearchButton.module.css` | Estilos do fake-input, overlay, modal e lista de resultados |

**Características do fake-input (trigger na MenuBar):**

- Aparência de campo de texto desativado com ícone de lupa e placeholder "Buscar estudos…"
- Badge `⌘ K` (Mac) ou `Ctrl K` (Windows/Linux) detectado via `navigator.platform`
- Hover com aumento de opacidade da borda e fundo

**Características do modal de busca:**

- Overlay com `backdrop-filter: blur(4px)` e fundo escurecido
- Modal com animação `slideDown` (`cubic-bezier(0.16, 1, 0.3, 1)`) e `fadeIn` no overlay
- Campo de busca real com `autoFocus`, placeholder e botão de limpar (`✕`)
- Resultados filtrados em tempo real por: título, descrição, categoria e tags
- Máximo de 6 resultados quando sem query; 8 quando com query

**Navegação por teclado:**

| Tecla | Ação |
| --- | --- |
| `Ctrl+K` / `Cmd+K` | Abre/fecha o modal em qualquer página |
| `↑` / `↓` | Navega entre os resultados |
| `↵ Enter` | Abre o estudo selecionado |
| `Esc` | Fecha o modal |

**Arquitetura de dados (sem fetch em runtime):**

O índice de busca é construído no servidor em build-time e passado ao componente via props, sem qualquer requisição HTTP em runtime:

```bash
getStudies() → MenuBar (async Server Component) → studyIndex prop → SearchButton (Client Component)
```

### 🐛 Correções de Erros

#### 3. API Route incompatível com `output: 'export'`

**Erro:**

```bash
Error: export const dynamic = "force-static" not configured on route
"/api/search" with "output: export"
```bash
```

**Causa:** A implementação inicial da busca usava uma API Route (`src/app/api/search/route.ts`) para servir o índice de estudos. O `next.config.ts` configura `output: 'export'` para geração de site estático (GitHub Pages), modo no qual API Routes são proibidas por exigirem um servidor Node.js em runtime.

**Consequência em cascata:** O `fetch('/api/search')` retornava `500 Internal Server Error`, causando erro de JSON no cliente:

```bash
SyntaxError: Unexpected token 'I', "Internal S"... is not valid JSON
```

**Solução:**

1. API Route `src/app/api/search/route.ts` **removida**
2. `MenuBar.tsx` convertido para `async function` — chama `getStudies()` diretamente e monta o `studyIndex`
3. `SearchButton.tsx` refatorado para aceitar `studyIndex: StudyIndex[]` como prop, eliminando todos os estados e `useEffect` relacionados ao fetch

#### 4. Versões incompatíveis entre `react` e `react-dom`

**Erro:**

```bash
Incompatible React versions:
  - react:      19.2.7
  - react-dom:  19.2.4
```

**Causa:** O `package.json` tinha `"react-dom": "19.2.4"` enquanto o `react` havia sido atualizado para `19.2.7`. As duas devem ter a mesma versão exata.

**Solução:**

```bash
pnpm add react-dom@19.2.7
```

```diff
// package.json
- "react-dom": "19.2.4"
+ "react-dom": "19.2.7"
```
